# flow-chart.io — AI Diagram Generator for Software Engineers

**[flow-chart.io](https://flow-chart.io)** is an AI-powered diagram generator built specifically for software engineers, architects, and IT professionals.

Describe a diagram in plain language and get back a fully editable diagram — not a screenshot, not a locked image. Every node, connector, label, and lane is a live object you can select, move, rename, and restyle.

## Supported diagram types

- **BPMN 2.0** — process diagrams with events, gateways, tasks, pools, and lanes
- **C4 architecture** — context, container, and component views for software systems
- **UML** — class, sequence, activity, and state diagrams
- **Cloud architecture** — AWS, GCP, and Azure infrastructure diagrams
- **Entity-relationship diagrams (ERD)** — data model diagrams
- **Threat model diagrams** — STRIDE-based security architecture
- **DevOps pipeline diagrams** — CI/CD and GitOps flows
- **Network diagrams** — topology, VLAN, and firewall diagrams
- **Org charts**, **swimlane diagrams**, **sequence diagrams**, and 8 more types

## What makes it different

draw.io, Lucidchart, and Miro are manual-first tools. flow-chart.io is AI-first: you describe the diagram, the AI generates a structured scene graph of typed objects. Every generated diagram is fully editable from the first result — no intermediate redrawing step.
